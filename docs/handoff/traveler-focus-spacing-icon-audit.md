# Login focus, Location Trip spacing and Traveler launcher icon

14 November 2026 · `feature/mobile-openapi-contracts` · follow-up to `c89da38`. This checkpoint addresses the owner's three requests: stable login fields while active, padding/spacing in Location Open Trips, and the purple Floopel app icon.

## Changes and reproduction

**Login.** The shared `FloopelFormTextField` recalculated external label space from the label's animated measured height and focus state. A native frame-by-frame regression reproduced a field changing **57.04 → 60.37 → 57.04 dp**, moving the following field by **3.33 dp**. Label space now remains allocated across expanded/floating transitions and retains enough room for wrapped labels. Single-line fields also reserve their editable line and label overlap as fonts grow. This second reservation closes a residual 200% font failure found during testing. Multiline content can still grow naturally; focus, keyboard actions, password handling and submission contracts remain with their existing owners.

The four new native cases cover blank focus transfers at 100%, 130% and 200% Compose font scale, plus actual Login → Android IME → focus transfer → typing → password visibility. Final sampled height and following-field position ranges are **0 dp** at all three scales. These font overrides use LocalDensity; they are not a claim of testing every Android system font setting. The actual keyboard case uses OS font scale 1.0 and the existing IME provider. The initial failed baseline and the subsequent large-font correction are distinguished from the final passing run.

**Location Open Trips.** Fresh [Figma 53:1225](https://www.figma.com/design/ifQcOxbjGTXw9aNH2JGl9g/Floopel-Mobile?node-id=53-1225) specifies title 17/23, metadata 13/18 and action 14/19. Default text leading was trimmed, producing line boxes of **43.33 dp for a two-line title, 15.56 dp metadata and 16.30 dp action**. The consumer now preserves the complete line boxes with `LineHeightStyle.Trim.None`. Final measurements are approximately 46.67/18.15/19.26 dp, within pixel rounding of the Figma targets 46/18/19. This restores vertical breathing room with long real titles. A new regression fails before the change and passes afterward. Existing 16 dp outside gutters, 76 × 80 dp photos, 12 dp image/text gap, 4 dp text gaps and 8 dp between items are retained and checked. Long titles still use two lines and ellipsis; rows grow with content instead of clipping the action. API-supplied covers remain dynamic. No map, data contract, stock photo or static Figma screenshot is introduced.

**Launcher.** Traveler previously declared no application icon, so Android used a default icon. Both main-manifest icon entries now resolve the existing Floopel brand geometry with native purple tint **#3730A3** on white. Every path, intrinsic dimension and viewport from the existing brand vector is retained. Adaptive foreground/background and monochrome layers, plus API 24–25 legacy/round resources, follow [Android's adaptive-icon guidance](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive). The 48 dp mark within the 108 dp adaptive canvas was visually checked inside the Android 15 launcher's circular mask. Both flavors inherit these main resources; only the development APK was built/installed. The old production APK still installed on the emulator is a separate application and was not replaced.
