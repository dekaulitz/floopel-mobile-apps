# Quest Group overview and management: 8 November 2026

Scoped finding **VD-QG-MGMT-01**, `quest-group-overview-management-composition-20261108-0513`, was checked against the Android [manager overview 397:8120](https://www.figma.com/design/ifQcOxbjGTXw9aNH2JGl9g/Floopel-Mobile?node-id=397-8120), [member overview 397:8222](https://www.figma.com/design/ifQcOxbjGTXw9aNH2JGl9g/Floopel-Mobile?node-id=397-8222), and [management 397:8429](https://www.figma.com/design/ifQcOxbjGTXw9aNH2JGl9g/Floopel-Mobile?node-id=397-8429). Fresh design context and screenshots were read with Code Connect mappings. The change separates the overview from the management form; it does not claim whole Quest gameplay parity.

## Change and data ownership

The old overview mixed plain roster text with recipient input, sent invitations, inline transfer and disband. The overview now presents the Quest context, authoritative `memberCount` / `sizeLimit`, role guidance, and individual member cards. Cards use the shared 16dp shape and surface token, 16dp padding, 12dp internal gap, minimum 84dp height, and 16sp/13sp text. The content column uses 20dp gutters and 16dp gaps. The root retains its pinned shared toolbar and mapped back icon.

Only a resolved current profile matching the current available group's manager can enter **Kelola kelompok**. Its local mode keeps the group ID, Quest slug, country/location context and original overview route in the stack. The mapped form field and shared 48dp secondary actions expose the existing invite, sent-invitation, transfer and disband capabilities. Username validation and capacity come from existing contracts; pending invitations do not replace authoritative membership counts. Members, unavailable groups, loading or failed profile reads do not acquire manager controls. A role change discovered on refresh removes those controls.

The same-group recipient draft survives sent-invitation navigation, Back, and unknown-result recovery. Management Back and cancellation of transfer/disband return to the same overview without a write. An acknowledged fixture disband exits both management and overview to the existing origin, avoiding a dead group screen. Existing actor/generation guards and the native command journal remain responsible for result recovery; no automatic command replay, new endpoint or new backend policy was added.

Roster progress is a nullable projection. Null may reflect unavailable/private progress, so it reads **Progres belum tersedia**, never zero or an inferred not-started state. An explicit `not_started` status uses **Belum mengambil Quest**; known activity counts retain their API values. Quest locations appear only when already available from a successfully loaded matching Quest reader. Production contains no Nadia/Magelang/count sample fallback. Quest Group capacity is independent of Open Trip's five participants plus one organizer.

## Qualifications

- The existing **Detail Quest** entry remains. The roster does not provide the owner's participation ID or complete execution eligibility, so this change does not infer a direct Take/Continue action from another member's progress. The frame's direct gameplay CTA remains a separate qualification.
- Shared mapped form/button behavior, including focus and disabled styling, is retained. This is scoped overview/management composition evidence, not every visual state of the entire Quest Group flow.
- Review-before-send frames 397:8533/8637 are not implemented by this finding. Cancellation-of-invitation UI and append-error presentation remain separate qualifications; existing pagination/recovery regressions are preserved.
- iOS compilation/native UI and TalkBack/VoiceOver are **NOT_RUN**. Mac/Xcode and an assistive-technology session are still required. Dark mode, physical devices, release signing and real private mutations are not accepted by this fixture run.
- Foreign local `.gitignore` and Android `styles.xml` edits are preserved and excluded. The latter was compiled locally; source fingerprints record those execution bytes rather than promising a portable checkout byte match.
